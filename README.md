# VulnScanner - Vulnerability Assessment Tool

## Overview

VulnScanner is a lightweight vulnerability assessment tool designed to identify potential security weaknesses in target systems. It performs security reconnaissance, scans open ports and services, analyzes vulnerabilities, and generates structured reports to assist in security testing.

This project focuses on understanding the vulnerability assessment workflow used during penetration testing and security auditing.

---

## Features

- 🔍 Port and service scanning
- 🛡️ Vulnerability identification and assessment
- 🌐 Target reconnaissance
- 📊 Structured vulnerability report generation
- ⚡ Automated security scanning workflow
- 🔎 Basic security analysis of detected services

---

## Technologies Used

- **Programming Language:** Python
- **Security Tools:** Nmap
- **Libraries:** Requests, Socket, OS, JSON
- **Operating System:** Linux / Windows

---

## Project Workflow

1. User provides the target IP address or domain.
2. The scanner performs reconnaissance and information gathering.
3. Open ports and running services are identified.
4. Detected services are analyzed for possible vulnerabilities.
5. Scan results are generated into a structured report.
